# 🚀 Практическая работа №4: Массивы и методы перебора в JavaScript

Репозиторий содержит выполнение лабораторной работы по изучению и применению современных методов перебора массивов в JavaScript (`.map()`, `.filter()`, `.find()`), а также их композиции (Method Chaining).

## 📋 Обзор проекта
* **Файл скрипта:** `array-lab.js` 
* **Технологии:** JavaScript (ES6+), Node.js (для запуска консольных тестов)
* **Тестовый стенд:** Массив объектов `products`, эмулирующий каталог интернет-магазина (электроника, аксессуары, адаптеры).

---

### 04. Отработка метода `.find()`: Поиск конкретного элемента
Поиск единичных объектов в массиве:

2. Поиск первого товара с высоким рейтингом (\(\ge 4.9\)).
3. Проверка поведения метода при поиске несуществующего элемента (возврат `undefined`).

### 05. Композиция методов: Построение цепочек (Method Chaining)
Продемонстрировано объединение методов перебора в единый конвейер (pipeline). Скрипт отбирает популярные товары в наличии, а затем трансформирует их структуру для витрины хитов.

```javascript
const showcaseProducts = products
  .filter((item) => item.inStock && item.rating >= 4.5)
  .map((item) => ({ ... }));
```

### 06. Итоговое задание: Модуль `CatalogManager`
